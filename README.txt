LIGHT & FORM — 3D CIRCULAR ROTUNDA GALLERY
==========================================

1. Drop any .jpg, .jpeg, .webp, or .png images into the "assets/" folder
   (e.g., photo-01.webp, photo-02.jpg, photo-03.png, up to photo-36).
2. Serve with any local HTTP server (e.g., "npx serve ." or "python -m http.server")
   OR open index.html directly and click "+ Load Photos" in the top bar.
3. Every frame automatically adapts to your image's native aspect ratio without cropping.
